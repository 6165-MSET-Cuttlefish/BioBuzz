# BioBuzz

FTC team 6165 MSET Cuttlefish's 2026–27 BIOBUZZ code: a single-module Android app on the FTC SDK, Pedro Pathing, Sloth hot reload and slothboard.

Requires JDK 17 (the Gradle daemon is pinned to it) and Android Studio Narwhal 3 Feature Drop or newer. Deploy with the **TeamCode** run configuration (full install) or **deploySloth** (hot reload), set up per [Sloth's README](https://github.com/Dairy-Foundation/Sloth); `CLAUDE.md` says when to use each.
